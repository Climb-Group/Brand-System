# Presets

The five presets are the only grounds a ClimbUK section uses. Each one sets the heading, body, link, accent and button colours together, so a section never mixes them by hand.

| Preset | Ground | Use |
| --- | --- | --- |
| 1 | White | Reading-heavy pages, forms, the release ladder |
| 2 | Light Grey | A quiet change of pace between dark sections |
| 3 | Dark Brown | The default ground |
| 4 | Climb Orange | Calls to action and the close, large white text only |
| 5 | Charcoal | Tickets and audience sections |

Add the class `climb-p1` to `climb-p5` to a section. In this hub, sections on presets 1, 2, 3 and 5 follow the theme toggle; preset 4 and photo sections stay as they are in both themes.
