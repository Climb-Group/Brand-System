## Usage notes

<!-- @readme.text -->
Tags name formats and topics. They are outlined, never filled, so they do not compete with buttons.

<!-- @readme.text -->
The live label (`climb-live`) adds a pulsing orange dot. Use it only for something that is happening now: tickets on sale, a live stream, doors open. The pulse stops under reduced motion.
