# Templates

Files to install on people's machines so documents, sheets, decks and videos start on brand, for ClimbUK, ClimbGroup and Climb27.

- `office/`: Word (`.dotx`: letterhead, report, proposal, press release, meeting notes), Excel (`.xltx`: event budget, partner pipeline, run sheet, content calendar) and PowerPoint (`.potx`: 19 layouts, 14 example slides) per brand, plus the desktop fonts, Office theme files, LibreOffice copies and previews. Install guide in `office/README.md`.
- `video/`: 4K 25fps lower thirds, stickers, a slab wipe, title and end cards, background loops, DaVinci Resolve Fusion titles (`.drfx`), a Premiere Pro sequence, the grade LUT and caption settings. Install guide in `video/README.md`. The motion clips ship as a release download.
- `m365/`: Microsoft 365 and Teams Premium branding: meeting themes, 36 meeting backgrounds, a branded reaction, the organisation theme, app launcher tiles, a Teams app for Odoo and the sign-in page, with an admin-centre setup guide in `m365/README.md`.
- `_build/`: the scripts that make all of it from the tokens, logos and photos.

Each template uses the token colours and the brand fonts, and meets WCAG 2.2 AA.
