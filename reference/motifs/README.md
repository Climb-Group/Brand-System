# Original motif vectors (style reference for icons and doodles)

These are the original ClimbGroup background artworks as vectors. They're the reference for how the brand's
hand-drawn elements look:
- smooth, tablet-drawn shapes with rounded ends
- organic blobs layered over each other
- small doodles: squiggle "steam" lines, an X, a dot trio, a dashed arc, a speech bubble, a concentric target,
  rounded tiles, and twin bars
- background layers in Charcoal/grey at low contrast, which give depth behind the foreground orange and white shapes

Each `*.svg` holds editable paths. `*_preview.png` is a 700px render, and `app-store-icon.png` shows the doodles
used together on one tile. New icons should match this hand: a single smoothed stroke weight, rounded caps and
joins, slightly imperfect curves (not shaky ones), and optional low-opacity back shapes for depth.
