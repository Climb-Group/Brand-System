Analyse the attendee feedback in {{feedback}} for a ClimbUK edition.

1. Group the comments into themes (agenda, speakers, networking, the ClimbGroup Event App, food, access, value). Give each theme a count and a sentiment.
2. Quote two short, typical comments per theme, with no names or identifying details.
3. List the five most fixable problems, each with one practical change for the next edition.
4. Note anything about accessibility or safety separately, even if only one person raised it.

Do not invent comments. Keep this internal; any quote used in public needs the person's consent first.
