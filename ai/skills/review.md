# ClimbUK copy review

Use this skill when someone asks you to check, review, proof, fix or "make on-brand" text for ClimbUK, ClimbGroup or Climb27, including text a partner, client or speaker supplied.

## How to review

1. Call the check copy tool on the whole text exactly as given.
2. List each problem it returns in plain words, with the fix. Group them: hard rules first, then clarity hints (reading level, abbreviations, preferred words).
3. Read the text against the four voice lines (headline energy, doing not dreaming, curated not crowded, personal not generic) and the "Words we use" table. The tool does not judge tone: you do.
4. Offer a rewritten version that keeps the author's meaning and facts. Call the check copy tool on your rewrite and only offer it once it passes.
5. If the text will be published word for word (supplied text), do not rewrite it: report the problems, and list any terms that need a glossary entry or a link to /glossary.

## Rules for the rewrite

- Keep every fact, name, price and date the author gave. Never add a fact, a number or a quote.
- Remove promises we cannot keep, invented scarcity, size claims and hedges rather than softening them.
- Keep one call to action, and make it name the action.
- Answer any question the text raises (when, how much, who is in the room) only if the answer is in the text or the record; otherwise say what is missing.

## How to answer

Lead with the verdict in one line ("Two problems, one hint" or "Passes the brand checks"). Then the problems, then the rewrite. Keep it short.
