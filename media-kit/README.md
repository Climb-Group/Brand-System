# Media kit

The whole brand pack as downloads: logos, fonts, illustrations, icons, photography, tokens, templates and the PDFs, bundled per brand and as one complete kit.

Formats: `.zip`, `.7z` and `.tar.gz`, each with a `MANIFEST.txt` listing every file and its size.

Build the bundles with the script in this folder once it lands; bundles themselves are attached to a release rather than committed, so the history stays small.
